## 使用入口

Storybook：`Patterns / Product Trend Chart`，故事源文件为同目录 `ProductTrendChart.stories.tsx`。示例直接复用 `ProductTrendChart`、`SeriesSelector` 和 `TrendPointMatrix`，全部为确定性的虚构数据，不访问 API 或数据库。

本地启动：在 frontend 使用既有 `storybook` 脚本（默认端口 6006）。Reference 展示完整交互；其余故事展示合计、重合、缺失/零/部分数据、比率、选择上限、窄屏、空数据和单日。Controls 的 metric 可切换五种指标，width 可调整容器宽度。

## 后续图表应沿用的基准

- 优先复用现有组件；按业务含义调整，不复制独立的图表实现。完整候选身份集合传入 labels，保证取消或重排系列后配色与线型稳定。
- 线条使用当前圆角、线宽、空心节点及配色，以颜色、线型和文字共同识别；缺失点断线，不平滑插值伪造趋势。
- 生长动画仅在数据/指标变化或主动重播时触发；悬停与日期查看不重播，遵守 reduced-motion 偏好。
- 独立点只提示该点；同日期且精确值相同才合并为重合组。提示框可避让视口，图表根名称用 ARIA，避免原生 title 与自定义 tooltip 重叠。
- 图例聚焦是突出曲线，不删除数据；恢复按钮恢复全部曲线。系列选择按实际候选数量说明，至少一项、同时最多八项。
- 图表、提示、每日读数和矩阵保持相同指标/单位与精度。销售额币种由报告决定；转化率当前为六位小数比率，不直接追加百分号。零值、缺失报告、分母为零和部分数据不混同。
- 保留日期滑杆及精确值矩阵作为核对入口；窄屏工具栏换行，矩阵在自身区域横向滚动。
- 页面异步筛选沿用 ProductDetailPage 的响应与 view 一起更新机制，等待时不卸载图表，不把新指标单位套在旧数值上。Storybook 是同步组件示例，不冒充接口/权限/异步切换验收。

后续修改相关交互时同步更新对应故事，按影响范围验证；不因维护 Storybook 自动启动全量回归或发布门禁。
