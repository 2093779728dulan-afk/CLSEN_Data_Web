# 工厂地区选择数据

- 来源：[modood/Administrative-divisions-of-China](https://github.com/modood/Administrative-divisions-of-China)
- 固定版本：c49d495b40ac73eb1a66f6eeae5f8fd10696f035，dist/pc.json；2026-10-23读取。
- 本地文件：chinaProvinceCities.json；31个省级地区、451个下级选项（含直辖市区县及省直管县级单位）。不是全球城市库，也不代表实时行政区划。
- 国家/地区中文显示使用浏览器 Intl.DisplayNames；港澳台及海外地点的详细地址保留在地址字段。
- 仅静态选项，运行时不访问外部服务，不用于推断历史业务地区。
