# 可折叠工作区壳层设计

## 目标

优化发布数据工作区的顶栏、桌面侧栏和账号连接区，减少无效留白，让用户可以主动释放横向空间，同时保持导航、站点边界和连接状态随时可识别。

## 范围

- 桌面侧栏支持在 238px 展开态与 72px 折叠态之间切换。
- 折叠选择保存在浏览器本地存储中，下次打开沿用。
- 顶栏重组站点、数据域、环境和报告时区信息，降低高度并增强层级。
- 账号区使用头像缩写、姓名、连接状态和独立退出操作。
- 860px 以下继续使用现有横向导航，不应用桌面折叠宽度。

不调整路由、权限、退出会话、站点配置或业务数据接口。

## 交互设计

侧栏品牌区提供可聚焦的折叠按钮，使用 `aria-expanded` 和明确的“收起侧栏”或“展开侧栏”名称。折叠后保留品牌缩写、导航标记和账号头像；导航链接继续具有完整无障碍名称，并通过 `title` 提供鼠标悬停提示。站点边界的详细说明在折叠态隐藏。

切换只改变壳层展示状态，不触发导航或数据请求。读取本地存储失败时默认展开；写入失败不影响本次操作。

## 视觉设计

延续现有蓝白、高密度运营工作台：主蓝 `#1769aa`、深墨 `#17324d`、浅灰蓝 `#edf4fa`、边界蓝灰 `#c7d6e2`、连接绿 `#287a55`。不引入新的装饰色或字体依赖。

侧栏的识别特征是“一条连续工作轨”：展开态显示图标与文字，折叠态只保留居中的方形标记，当前路由仍由蓝色背景与边缘指示线表达。顶栏改为紧凑的上下文条，左侧为站点与“每日数据”，右侧为环境和时区。账号区采用克制的两行身份卡，不做大型个人资料卡。

## 状态与响应式

- 展开：显示完整品牌、导航文字、数据边界和账号详情。
- 折叠：显示品牌缩写、导航标记、账号头像和展开按钮；隐藏辅助文字。
- 离线：连接指示继续使用既有告警颜色和“API 不可用”文案。
- 小屏：保持现有横向导航；品牌和账号区按现有移动端规则隐藏。
- 减少动态效果偏好：折叠过渡遵循已有 `prefers-reduced-motion` 规则。

## 验证

仅补充或调整壳层相关测试：折叠按钮的名称与状态、点击后壳层状态、已保存偏好的恢复，以及退出操作不受影响。随后运行 App 定向测试、相关 ESLint、TypeScript 和一次浏览器人工核对，不运行完整前端测试或 Collect。
