# 日期工作台结构增强表格设计

日期：2026-08-14

## 1. 背景

当前日期工作台已经支持完整原始列、单元格自动保存、撤销、校验和发布，
但所有数据列使用同一宽度、表头只有一层、横向滚动时缺少商品上下文，
大量列同时出现时仍然接近原始 CSV，而不是高效的数据核验工具。

本设计参考 `CLSEN2026库存变动表格20260725.xlsx` 的信息组织优点：

- 将商品身份列集中展示；
- 用多层表头表达字段区段；
- 通过轻量分隔识别连续商品组；
- 让列宽匹配字段含义；
- 保持高密度横向数据视图。

本设计不复制参考文件中的大量手工底色、超宽时间矩阵、辅助空表或公式错误，
也不把日期审核工作台改造成库存计划模型。

## 2. 目标

在不改变现有版本、权限、编辑和发布语义的前提下，使用户能够：

1. 横向滚动时始终看到行号和商品身份；
2. 通过字段组快速理解当前列区段；
3. 按字段含义获得合理的初始列宽；
4. 拖动调整列宽并在刷新后恢复个人设置；
5. 搜索、显示、隐藏和重排当前视图中的列；
6. 在不改变 CSV 原始行顺序的情况下识别连续商品组；
7. 清楚区分修改、保存、冲突、校验和只读状态。

## 3. 非目标

- 不增加 Excel 公式、拖拽填充、跨单元格粘贴或任意工作表能力；
- 不改变 CSV 原始证据、版本化列 ID 或统计映射；
- 不把个人视图偏好写入业务数据库；
- 不改变自动保存、撤销、校验、发布和历史修订接口；
- 不自动按商品重排行，只增强当前顺序中的组边界。

## 4. 页面结构

页面继续使用以下顺序：

1. 日期工具栏与保存状态；
2. 经营报告/退货报告标签；
3. 搜索、只看修改和列设置；
4. 结构增强数据表；
5. 分页与底部审核操作栏。

无数据状态、识别确认状态和发布控制保持现有流程。

## 5. 两层分组表头

表头由字段组行和原始字段行组成。

### 5.1 字段组

经营报告优先使用：

- 商品信息；
- 流量；
- 转化；
- 销售；
- 其他原始字段。

退货报告优先使用：

- 商品信息；
- 退货信息；
- 原因与处理；
- 数量与金额；
- 其他原始字段。

标准字段通过 `standard_field_name` 进行确定性分类。扩展原始列使用经过测试的
NFC 标准化表头规则分类；未匹配列进入“其他原始字段”。分类仅用于显示，
不会改变列 ID、存储、统计参与状态或原始顺序。

### 5.2 原始字段行

第二层始终显示原始 CSV 表头，并保留：

- “统计”标记；
- 当前排序方向；
- 列宽拖动手柄；
- 完整表头悬停文本。

同一字段组的列在当前视图中连续时，上层组标题跨越这些列；用户重排后若同一组
被拆分成多个区段，则分别显示同名组标题，不跨过其他组。

## 6. 冻结身份列

冻结顺序为：

1. 行号；
2. 后端 `is_key=true` 的可见列；
3. 经营报告中的父 ASIN、子 ASIN、SKU、FNSKU、标题/商品名称；
4. 退货报告中的 SKU、ASIN、FNSKU、标题/商品名称。

冻结列仍遵守当前视图顺序。系统根据实际列宽计算每列 `left` 偏移，
避免硬编码位置。桌面端冻结区不超过可视宽度的 45%；超过时按上述优先级减少
补充冻结列，但永远保留行号和至少一个商品身份列。

关键身份列可以调整宽度和顺序，但不能全部隐藏。

## 7. 列宽与调整

推荐初始宽度：

| 字段类型 | 推荐宽度 |
| --- | ---: |
| 标题、商品名称 | 300px |
| ASIN、SKU、FNSKU | 144px |
| 日期、状态、原因 | 152px |
| 数量、比例、金额 | 104px |
| 普通文本扩展列 | 168px |

最小宽度为 72px，最大宽度为 480px。长文本保持单行省略；悬停显示全文，
编辑框聚焦时可在单元格内部横向滚动，不允许跨入相邻列。

用户通过表头右边界拖动调整宽度。拖动只更新视图状态，不触发业务保存；
在指针释放或键盘调整结束后写入个人偏好。调宽手柄支持键盘左右键，
并提供可访问名称。

## 8. 列设置与个人偏好

列设置面板支持：

- 搜索列名；
- 显示或隐藏非关键列；
- 拖动调整视图顺序；
- 一键只显示统计字段；
- 恢复 CSV 原始顺序；
- 恢复系统推荐列宽。

偏好保存在浏览器 `localStorage`。偏好键由当前用户 ID、站点 ID、报表类型和偏好
版本组成，不包含数据集 ID、日期或业务值，避免同一浏览器上的不同账号相互继承
设置。保存内容仅包括稳定列 ID、可见状态、视图顺序和宽度。读取时按当前版本列
架构进行合并：

- 消失列被忽略；
- 新列按原始位置加入并默认可见；
- 无效宽度被限制到允许范围；
- 损坏 JSON 或不支持的偏好版本整体回退默认值；
- 关键列隐藏配置由客户端根据服务器返回的当前列元数据纠正，但不回写业务接口。

## 9. 排序与行分组

点击第二层表头切换升序、降序和原始顺序。排序参数继续写入 URL 并交给现有
服务端查询，不在浏览器对当前页做伪排序。

行分组不改变服务端顺序。客户端只比较相邻行：

- 经营报告优先使用父 ASIN；缺少时使用稳定 SKU 款式前缀；
- 退货报告优先使用 SKU，再回退 ASIN；
- 无可靠分组键时不创建人工分组。

组变化处增加细分隔线、组名提示和非常浅的交替底色。分页第一页中的首行可以
显示组名，但不得声称它是跨页组的真正起点。

## 10. 组件边界

- `columnPresentation.ts`：纯函数计算字段组、语义宽度、对齐方式和冻结优先级；
- `columnPreferences.ts`：解析、合并、版本化并保存个人偏好；
- `WorkbenchHeader.tsx`：两层表头、排序、调宽和冻结偏移；
- `EditableDataGrid.tsx`：行、单元格、商品组边界和键盘编辑；
- `ColumnSettingsPanel.tsx`：列搜索、显示、顺序和重置；
- `DateWorkbenchPage.tsx`：加载、路由、上传和审核命令编排。

视图组件不能自行改写权威工作台数据。单元格服务器状态仍由现有编辑 reducer
和查询响应控制。

## 11. 状态与颜色

- 字段组和当前标签：中深蓝；
- 冻结身份列：极浅蓝灰；
- 已修改单元格：淡黄；
- 保存失败、冲突或校验阻断：淡红；
- 刚保存成功：短暂淡绿，随后恢复普通背景；
- 商品组：细分隔线和接近白色的交替底色。

业务状态色优先于商品组底色。颜色之外还必须有文字、图标或可访问状态描述。

## 12. 响应式与无障碍

- 1280px 以上显示完整冻结策略和列设置；
- 768–1279px 降低冻结列数量，保留行号和必要商品身份；
- 390–767px 以查看和少量编辑为主，保留横向滚动，不转换成卡片；
- 表头保留正确 `scope`、`aria-sort` 和键盘顺序；
- 调宽、列设置、排序和编辑均可不用鼠标完成；
- 200% 缩放下不得出现相邻单元格文本重叠或固定操作栏遮挡。

## 13. 测试

### 13.1 单元测试

- 经营/退货字段组分类；
- 未知列回退；
- 推荐宽度和宽度限制；
- 冻结优先级与最大冻结区；
- 偏好损坏、版本迁移、新增列和消失列；
- 商品组键和边界计算。

### 13.2 组件测试

- 两层表头与拆分字段组；
- 拖动/键盘调宽及刷新恢复；
- 显示、隐藏、重排和重置；
- 服务端排序 URL；
- 商品组分隔但不重排行；
- 编辑、保存、失败、冲突、撤销和只读状态。

### 13.3 浏览器验收

使用去标识化经营和退货样表，在 1280、768 和 390px 下检查冻结列、横向滚动、
长文本、列设置、编辑刷新、撤销和底部操作栏。

## 14. 完成标准

- 超宽表横向滚动时始终保留必要商品上下文；
- 用户可通过字段组定位列区段；
- 列宽符合字段含义且可调整、可恢复；
- 个人偏好不会影响业务数据或其他用户；
- 原始列、原始行顺序和所有版本语义保持不变；
- 所有编辑、权限和发布回归测试继续通过。
