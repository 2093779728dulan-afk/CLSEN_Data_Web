# 查看人员：已发布经营看板

看板只读取当前发布版本。草稿、失败导入、历史版本和未完成修订不会进入指标。

## 使用方式

1. 打开“已发布看板”，选择月份或日期范围。
2. “汇总”查看销售、订单、退货等核心指标。
3. `legacy_parser` 模式下，“商品”按旧 SKU/ASIN 语义查看；`p0_catalog` 模式会整套切换到独立的“产品分析”列表与稳定款式详情，不会在同一页面混用两种身份来源。
4. “退货”可切换报告日或事件日口径。事件日会按当前站点统计时区计算。
5. 查看页面附带的发布版本和站点配置版本，确认数据口径。

## 数据口径

- 报告日口径按每天隔离的数据集与当前发布指针统计。
- 事件日口径会同时引用发布版本和 `site_config_version_id`。站点时区变更后，新查询按新配置重新计算，旧配置版本仍可追溯。
- 当某天只有一类报表发布时，日期轨显示为蓝色；两类均发布后显示绿色。
- 页面不会展示完整订单号、物流牌照或原始单笔留言。

## 为什么数字没有立即变化

- 数据管理员的修改仍处于草稿：看板不会读取。
- 修订已校验但尚未发布：看板继续显示上一发布版本。
- 所选日期范围、报告日/事件日口径或站点时区不同。
- 后台任务失败不会让看板回退到旧缓存；当前版本直接查询 MySQL 发布指针。管理员可在“备份与任务”查看任务状态。

需要核对来源时，记录页面显示的数据版本和站点配置版本，由数据管理员在版本记录中追溯对应原文件、人工修改和发布事件。

商品标准名称、实际颜色/尺码、五指标与 partial/null 说明见[产品分析使用指南](./product-analytics.md)；商品身份审核见[商品主档使用指南](./product-catalog.md)。
